Introduction

Aura Documentation

Welcome to the Aura developer docs. Aura is an AI-powered email client built on Spring Boot with Gmail API integration and Gemini AI for smart triage, summarization, and compose.

Aura is currently in private beta. To get access, sign in with your Google account and request early access.

What is Aura?

Aura connects to your Gmail account via OAuth2 and provides a clean 3-pane inbox interface with AI features layered on top — email summaries, smart triage, AI compose, and one-tap unsubscribe.

Tech stack

BackendSpring Boot 3.2, Java 21
AuthSpring Security OAuth2 (Google)

Quick start

Get Aura running locally

From zero to inbox in under 10 minutes.

Prerequisites

You'll need Java 21+, MySQL, and accounts on Google Cloud Console and AI Studio.

1

Clone and open in VS Code

Open the project folder in VS Code with the Extension Pack for Java installed.

2

Create MySQL database

CREATE DATABASE aura;
CREATE USER 'aura_user'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON aura.* TO 'aura_user'@'localhost';
3

Configure application.properties

server.port=9091
spring.datasource.url=jdbc:mysql://localhost:3306/aura
spring.datasource.username=aura_user
spring.datasource.password=password
spring.security.oauth2.client.registration.google.client-id=YOUR_CLIENT_ID
spring.security.oauth2.client.registration.google.client-secret=YOUR_SECRET
gemini.api.key=YOUR_GEMINI_KEY
4

Run AuraApplication.java

Click the ▶ Run button above the main method in VS Code. Wait for Tomcat started on port 9091.

5

Open the app

Navigate to http://localhost:9091 and sign in with Google.

Authentication

Google OAuth2

Aura uses Google OAuth2 for authentication. Users sign in with their Google account and grant Gmail permissions.

Required scopes

openid
email
profile
https://www.googleapis.com/auth/gmail.readonly
https://www.googleapis.com/auth/gmail.send
https://www.googleapis.com/auth/gmail.modify

Before going public, you must complete Google's OAuth app verification. Until then, only test users added in Google Cloud Console can sign in.

Adding test users

1

Go to console.cloud.google.com → APIs & Services → OAuth consent screen

2

Scroll to Test users → click Add users → enter the Gmail address

3

Save. The user can now sign in immediately.

Core features

Inbox

The inbox fetches emails live from Gmail via the Gmail API. No email content is stored in Aura's database.

Core features

AI Triage

Aura uses Gemini to classify every email into one of four categories when you open it.

Categories

CategoryDescription
PriorityNeeds action from you today — requests, questions, approvals
Follow-upSomething you need to check back on or that needs a response
UpdateFYI notifications — deploy confirmations, PR merges, payouts
ArchiveNewsletters, promotions, receipts, automated digests

How it works

When you click an email, Aura calls POST /api/emails/{id}/summarize which sends the From, Subject, and Snippet to Gemini and returns both a summary and a triage category in one call.

Core features

AI Compose

Press C or click Compose with Aura to open the compose window. Type an instruction in the AI bar to generate a draft.

Example instructions

"Decline the meeting, suggest next Tuesday instead"
"Follow up on the proposal I sent last week"
"Thank them and ask for a 15-minute call this week"
"Write a professional reply accepting the offer"

Aura sends your instruction plus the context of the open email thread to Gemini, which returns a full email body ready to send or edit.

Core features

Search

API Reference

Emails API

All endpoints require authentication via session cookie (set after Google OAuth login).

MethodEndpointDescription
GET/api/emailsList inbox (max=50)
GET/api/emails/{id}Get single email
GET/api/emails/search?q=Search using Gmail syntax
POST/api/emails/sendSend email
POST/api/emails/{id}/summarizeAI summary + triage
POST/api/emails/{id}/smart-replies3 AI reply suggestions
POST/api/emails/{id}/archiveArchive email
POST/api/emails/{id}/starStar email
POST/api/emails/{id}/trashMove to trash
POST/api/emails/compose-aiAI draft from instruction

Send email — request body

{
  "to": "recipient@example.com",
  "subject": "Hello",
  "body": "Email body text",
  "inReplyToId": "optional-message-id"
}
